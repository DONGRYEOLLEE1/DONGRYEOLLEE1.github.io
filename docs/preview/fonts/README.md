# Pretendard Variable

공식 Pretendard v1.3.9의 수정하지 않은 전체 변수 글꼴이다. CSS family는 `Pretendard`로 연결하며 실제 굵기 범위는 45~920이다. 제목·본문·메타데이터는 같은 글꼴의 서로 다른 굵기를 사용하고, 코드는 시스템 모노스페이스를 사용한다.

`OFL.txt`를 함께 배포한다. 단일 HTML 시안에는 외부 연결 없이 열 수 있도록 원본 WOFF2와 라이선스를 함께 포함한다. 실제 사이트 구현에서는 이 파일을 별도 정적 자산으로 제공해 페이지 간 캐시를 공유한다. 이 시안은 한글 글리프를 제거하거나 글꼴 파일을 수정하지 않았다.
